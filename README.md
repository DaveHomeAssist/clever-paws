# Clever Paws

A calm, evidence-based cat training reference with local progress tracking.

Static single-page site — no build step, no backend. Progress is saved to `localStorage` per device.

## Local preview

Open `index.html` in a browser, or serve the folder:

```
python -m http.server 8000
```

Then visit `http://localhost:8000/`.

## Deploy

Hosted via GitHub Pages from the `main` branch root.
